# MusicAgent

一个本地音乐创作工作台：编辑旋律和伴奏，让 Agent 协助改谱，导入歌曲制作翻唱。

**[下载最新版：0.12.0-alpha.20](https://github.com/xiazhiaidao/musicagent-releases/releases/latest)** · Windows x64

## 新版功能

- 人声波形与可拖动字边界，原参考 / 当前歌声切换，实际音高测量曲线；边界调整支持撤销与重做。
- 局部重唱带邻字上下文合成，再仅替换选中字，并增加接缝过渡；自然度仍需实际试听确认。

- 逐字歌词与音符编辑：改字、指定拼音、调整音高与时长。
- 角色重唱：绮萱导唱结合所选 RVC 音色，修改后重新演唱并替换时间线对应时段。
- 自然音高、手绘曲线、颤音与滑音；上一步 / 下一步、局部试听和工程保存。
- 人声分离、RVC 翻唱、导入本地模型和文件夹识别；应用内按需下载环境。
- 多轨编排、可编辑伴奏、MIDI / WAV 导出，以及含音频的工程包迁移。

## 开始使用

1. 在 [Releases](https://github.com/xiazhiaidao/musicagent-releases/releases) 下载 EXE 安装，或解压 ZIP 后启动 MusicAgent.exe。
2. 更新前保存并关闭应用。已有工程与配置保留。
3. 用“使用向导”准备需要的环境；可先体验音符编辑和乐器试听。Agent 另需配置自己的模型接口。
4. 旧角色工程想使用新版导唱，在“填词与 AI 演唱 → 按谱声库”选择“绮萱 Qixuan 2.7”，保留角色音色后重唱。

安装包不附带歌曲、角色模型或模型接口密钥。角色音色需另行导入有权使用的 RVC 模型；歌声与翻唱处理在本机执行。角色重唱导唱下载需要兼容的64位Python 3.10–3.12。

当前为 Alpha，只完成本机验证，音质与速度依赖输入和模型。歌词识别为可修改初稿；按谱合成目前每次最多30秒单声部短句。
